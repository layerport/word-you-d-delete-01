# The Word You'd Delete From the Dictionary

Entry for the [make.fun bounty](https://make.fun/bounty/u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2)
"The Word You'd Delete From the Dictionary".

## The word

**defenestration**

## Why this word

Defenestration — the act of throwing someone (or something) out of a
window — is a word that sounds like a sneeze in a Latin lesson, and it
is the language's only single word for that very specific crime.
Erase it, and every deposed official, every unwanted houseguest and
every dramatic exit has to be described in full sentences. The gap it
leaves is the joke.

## How it works

`main.py` (Python 3.13, standard library only) writes exactly one word
— `defenestration` — to `$OUTPUT_DIR/entry.txt` (default `/output`).

```sh
python3 main.py
cat /output/entry.txt   # defenestration
```
